# Source Data

Progress stage: raw and shared data inputs before taxonomy work, baseline experiments, and fine-tuning.

Contents:

- `data/`: shared ODIL TSV / JSON files.
- `data/all.tsv`: full ODIL table used to build SFT samples.
- `data/classes.tsv`: TIMEL label / ID reference table.
- `data/timel_taxonomy.json`: TIMEL taxonomy source.
- `data/splits/`: train / dev split TSV files.
- `images.zip`: image archive.
- `images_with_links.csv`: image metadata / link table.
- `mandragore_nh_global_kw_grouped.csv`: Mandragore keyword grouped source CSV.
